# WIRED 2.0 — лаунчер для Android в атмосфере Serial Experiments Lain

Замена рабочего стола (как Nova / Microsoft Launcher) для Samsung Galaxy A36 (Android 15 / One UI 7), работает на Android 8+.
Холодный синий свет, пустота, тонкие часы, едва заметные ЭЛТ-полосы. Иконки приложений — настоящие, цветные.

> В лаунчере нет кадров и арта из аниме. Персонажа ставишь сам — своими картинками из галереи (в «Композиции» и в CRT-окне). Картинки никуда не загружаются, они копируются только в память телефона.

## Установка

1. На телефоне открой **https://github.com/Lawyye/launcher/releases/latest** и скачай `wired-launcher.apk`.
2. Открой файл и разреши установку из этого источника.
3. Если Play Protect предупредит — «Подробнее» → «Всё равно установить».
4. Открой **WIRED** → «Сделать главным экраном» → выбери WIRED.

Обновление ставится поверх, настройки сохраняются. Вернуть стандартный рабочий стол: Настройки → Приложения → Выбор приложений по умолчанию → Главный экран → One UI Home.

## Режимы главного экрана

| Режим | Что на экране |
|---|---|
| **Картинка** | твоё фото во весь экран, часы столбиком рядом с персонажем, док |
| **CRT-окно** | старый монитор с твоими картинками; включается как кинескоп после разблокировки |
| **Минимал** | встроенные обои «Провода», «Пустота» или системные обои |

**Композиция** (удержание на пустом месте → «Композиция и обои»): выбери фото, двигай пальцем, щипком меняй масштаб, двойной тап — сброс. Затемнение 0–80 %, фильтр (Wired / Призрак / Сигнал / Ч/Б / Оригинал), часы слева или справа.

**CRT-окно**: до 8 картинок, своя цветовая обработка, новая картинка при каждой разблокировке. Тап по монитору — следующая картинка, удержание — настройки окна.

## Управление

| Жест | Что делает |
|---|---|
| Свайп вверх | все приложения (The Wired) |
| Свайп вниз | шторка уведомлений |
| Удержание на пустом месте | режим экрана, композиция, настройки |
| Двойной тап | глитч |
| Удержание на приложении | в док / скрыть / о приложении / удалить |

В списке приложений: сетка или список, категории, частые приложения, поиск с подсветкой; Enter открывает первое совпадение, ниже — поиск в интернете, на картах и в магазине.

## Производительность

- **Экономия** — без эффектов и анимаций.
- **Баланс** (по умолчанию) — полосы, зерно и виньетка рисуются один раз из маленьких тайлов; включение монитора и глитч только по событию; всё на паузе, когда лаунчер не на экране.
- **Визуал** — плюс бегущая полоса и мерцание в CRT-окне (30 fps, только пока экран виден).

Иконки рендерятся один раз и лежат в кэше памяти, список приложений переиспользует строки — при прокрутке ничего не декодируется заново. Часы обновляются по системному сигналу раз в минуту, сеть и батарея — по событиям, без опроса.

## Сборка

APK собирает GitHub Actions на каждый пуш (`.github/workflows/build.yml`); релиз публикуется из ветки `main`.
Локально: Android Studio или `./gradlew assembleRelease` (JDK 17).

Код — Kotlin, без сторонних библиотек, только Android framework:

```
app/src/main/java/com/lawyye/wired/
  HomeActivity.kt        главный экран, жесты, живые данные
  Backdrop.kt            картинка/обои + сцена «Провода»
  CrtWindowView.kt       CRT-окно с анимацией включения
  Effects.kt             слой эффектов, часы
  DrawerView.kt          The Wired: сетка, список, поиск
  AppRepository.kt       список приложений, категории, кэш иконок
  SettingsActivity.kt    настройки
  ComposerActivity.kt    композиция картинки
  CrtImagesActivity.kt   картинки CRT-окна
  Theme.kt / Ui.kt / Widgets.kt   дизайн-система и компоненты
```

Шрифты Space Grotesk, Manrope и IBM Plex Mono лежат в `app/src/main/assets/fonts` под лицензией SIL Open Font License 1.1.

Ключ подписи `app/wired.keystore` лежит в репозитории, чтобы каждая сборка CI ставилась поверх предыдущей. Для личного лаунчера этого достаточно; минус — кто угодно может подписать им свою сборку, поэтому ставь APK только из этого репозитория.
