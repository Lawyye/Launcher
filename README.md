# WIRED 2.0 — лаунчер для Android в атмосфере Serial Experiments Lain

Замена рабочего стола (как Nova / Microsoft Launcher) для Samsung Galaxy A36 (Android 15 / One UI 7), работает на Android 8+.
Холодный синий свет, пустота, тонкие часы, едва заметные ЭЛТ-полосы. Иконки приложений — настоящие, цветные, или из любого набора иконок.

> В лаунчере нет кадров и арта из аниме. Персонажа ставишь сам — своими картинками из галереи (в «Композиции» и в CRT-окне). Картинки копируются только в память телефона: у WIRED нет разрешения на интернет, а из резервной копии Google картинки исключены (туда попадают только настройки). При переносе на новый телефон кабелем или через Smart Switch переезжает всё.

## Установка

1. На телефоне открой **https://github.com/Lawyye/launcher/releases/latest** и скачай `wired-launcher.apk`.
2. Открой файл и разреши установку из этого источника.
3. Если Play Protect предупредит — «Подробнее» → «Всё равно установить».
4. Открой **WIRED** → «Сделать главным экраном» → выбери WIRED.

Обновление ставится поверх, настройки сохраняются. Вернуть стандартный рабочий стол: Настройки → Приложения → Выбор приложений по умолчанию → Главный экран → One UI Home.

## Режимы главного экрана

| Режим | Что на экране |
|---|---|
| **Картинка** | твоё фото во весь экран, часы столбиком рядом с персонажем, док |
| **CRT-окно** | старый монитор с твоими картинками; включается как кинескоп после разблокировки |
| **Минимал** | встроенные обои «Провода», «Пустота» или системные обои |

**Композиция** (удержание на пустом месте → «Композиция и обои»): выбери фото, двигай пальцем, щипком меняй масштаб, двойной тап — сброс. Затемнение 0–80 %, фильтр (Wired / Призрак / Сигнал / Ч/Б / Оригинал), часы слева или справа.

**CRT-окно**: до 8 картинок, своя цветовая обработка, новая картинка при каждой разблокировке. Тап по монитору — следующая картинка, удержание — настройки окна.

## Управление

| Жест | Что делает |
|---|---|
| Свайп вверх | все приложения (The Wired) |
| Свайп вниз | шторка уведомлений |
| Удержание на пустом месте | режим экрана, композиция, настройки |
| Двойной тап | глитч |
| Удержание на приложении | в док / скрыть / о приложении / удалить |

**Наборы иконок**: любой набор из Google Play, сделанный для Nova или ADW (их большинство). Поставь набор → Настройки WIRED → приложения → «Набор иконок». Приложения, которых в наборе нет, остаются со своими иконками; «Тон» и «Моно» работают и поверх набора.

В списке приложений: сетка или список, категории, частые приложения, поиск с подсветкой; Enter открывает первое совпадение, ниже — поиск в интернете, на картах и в магазине. Поиск понимает не ту раскладку: «еудупкфь» найдёт Telegram, «ntktuhfv» — «Телеграм».

## Шторка WIRED сверху в любом приложении

Заменить шторку Samsung не может ни одно приложение без root, поэтому WIRED делает так: служба специальных возможностей кладёт над строкой состояния прозрачную полоску. Свайп вниз по ней открывает шторку WIRED поверх любого приложения.

Включение (один раз): Настройки WIRED → шторка → «Шторка WIRED сверху в любом приложении» → «Специальные возможности» → «Установленные приложения» → «Шторка WIRED». Если переключатель серый: «Сведения о WIRED» → ⋮ → «Разрешить ограниченные настройки», потом снова включить. Android так защищает приложения, поставленные из файла.

- Шторка Samsung — стрелка вверху шторки WIRED. Или в настройках выбери «левая половина» / «правая половина»: вторая половина края останется за Samsung.
- На заблокированном экране полоски нет: там всегда шторка Samsung, уведомления и переключатели WIRED не показываются.
- В горизонтальном положении (игры, видео) полоски тоже нет: верхний край с кнопками приложения остаётся за ним и за системой.
- «авто» рядом с яркостью — адаптивная яркость Samsung. Если сдвинуть ползунок, она выключается (иначе ползунок не действует), и это видно по кнопке.
- Закрыть: свайп вверх, «назад», «домой».
- Служба не читает содержимое экрана. Пока шторка закрыта, она не получает никаких событий от системы.

## Производительность

- **Экономия** — без эффектов и анимаций.
- **Баланс** (по умолчанию) — полосы, зерно и виньетка рисуются один раз из маленьких тайлов; включение монитора и глитч только по событию; всё на паузе, когда лаунчер не на экране.
- **Визуал** — плюс бегущая полоса и мерцание в CRT-окне (30 fps, только пока экран виден).

Иконки рендерятся один раз и лежат в кэше памяти, список приложений переиспользует строки — при прокрутке ничего не декодируется заново. Прогрев кэша идёт в фоне одной задачей: сначала док, потом частые, потом остальные, ровно в том размере, в котором рисует меню; при нехватке памяти у системы кэш отдаёт половину. Часы обновляются по системному сигналу раз в минуту, сеть и батарея — по событиям, без опроса.

Уведомления: пока шторка закрыта, WIRED только отмечает, что список устарел, — ничего не читает и не рисует. Открытая шторка собирает список в фоне и не чаще раза в 300 мс, иконки уведомлений кэшируются.

## Если что-то сломалось

Настройки → система → **Журнал сбоев**: последний сбой и записи системы о том, как завершался WIRED (зависания, нехватка памяти). Кнопка «Скопировать» — пришли этот текст, по нему видно точную строку кода. Журнал хранится только на телефоне.

## Сборка

APK собирает GitHub Actions на каждый пуш (`.github/workflows/build.yml`): сначала юнит-тесты, потом сборка и отчёт Lint; релиз публикуется из ветки `main` только если тесты прошли. К релизу прикладывается `mapping.txt` — по нему расшифровывается стек из журнала сбоев.
Локально: Android Studio или `./gradlew assembleRelease` (JDK 17).

Код — Kotlin, без сторонних библиотек, только Android framework:

```
app/src/main/java/com/lawyye/wired/
  HomeActivity.kt        главный экран, жесты, живые данные
  Backdrop.kt            картинка/обои + сцена «Провода»
  CrtWindowView.kt       CRT-окно с анимацией включения
  Effects.kt             слой эффектов, часы
  DrawerView.kt          The Wired: сетка, список, поиск
  AppRepository.kt       список приложений, категории, кэш иконок
  Shade.kt               шторка WIRED и уведомления
  ShadeService.kt        шторка поверх приложений (служба специальных возможностей)
  Logic.kt               чистая логика (поиск, ключи приложений) — покрыта тестами
  CrashLog.kt            журнал сбоев
  SettingsActivity.kt    настройки
  ComposerActivity.kt    композиция картинки
  CrtImagesActivity.kt   картинки CRT-окна
  Theme.kt / Ui.kt / Widgets.kt   дизайн-система и компоненты
```

Шрифты Space Grotesk, Manrope и IBM Plex Mono лежат в `app/src/main/assets/fonts` под лицензией SIL Open Font License 1.1.

Ключ подписи `app/wired.keystore` лежит в репозитории, чтобы каждая сборка CI ставилась поверх предыдущей. Для личного лаунчера этого достаточно; минус — кто угодно может подписать им свою сборку, поэтому ставь APK только из этого репозитория.
