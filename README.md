# WIRED — лаунчер для Android в стиле Lain

Замена рабочего стола (как Nova / Microsoft Launcher) в эстетике Serial Experiments Lain: чёрная пустота, ЭЛТ-полосы, HUD-перекрестия, RGB-глитч, терминал вместо иконок. Делался под Samsung Galaxy A36 (Android 15 / One UI 7), работает на Android 8+.

> В лаунчере нет кадров и арта из аниме — только оформление. Обои ставишь свои.

## Установка

1. На телефоне открой **https://github.com/Lawyye/launcher/releases/latest** и скачай `wired-launcher.apk`.
2. Открой файл. Samsung попросит разрешить установку из этого источника — разреши.
3. Если Play Protect предупредит — «Подробнее» → «Всё равно установить» (APK не из Google Play, это нормально).
4. Открой **WIRED** → в окне приветствия нажми **SET AS DEFAULT HOME** → выбери WIRED.

Вернуть стандартный рабочий стол: Настройки → Приложения → Выбор приложений по умолчанию → Главный экран → One UI Home.

Обновление: каждая новая версия появляется в Releases, ставится поверх старой, настройки сохраняются.

## Управление

| Жест | Что делает |
|---|---|
| Свайп вверх | все приложения (The Wired) |
| Свайп вниз | шторка уведомлений |
| Удержание на пустом месте | меню (обои, настройки) |
| Двойной тап | глитч |
| Тап по `lain@navi:~$` | поиск приложений с клавиатурой |
| Удержание на приложении | закрепить / убрать / скрыть / удалить / инфо |

В списке приложений: печатаешь — фильтрует, Enter — запускает первое совпадение; справа буквенный указатель.

## Настройки (`[cfg]`)

- **Фон**: VOID (чёрный), SYSTEM (системные обои), IMAGE (своя картинка) + DUOTONE (перекрашивает картинку в цвет акцента) + затемнение
- **Акцент**: WIRED BLUE, LAYER RED, PSYCHE PINK, NAVI GREEN, PROXY ICE, SIGNAL AMBER
- **Эффекты**: ЭЛТ-полосы, глитч (OFF/LOW/HIGH), бегущий фоновый код, секунды
- **Список**: иконки (нет / монохром / цвет), стиль закреплённых (TERMINAL или HYPERLINK как в 90-х), автоклавиатура, свой `user@host`, восстановление скрытых

## Сборка

APK собирает GitHub Actions при каждом пуше в `main` (`.github/workflows/build.yml`) и публикует в Releases.
Локально: Android Studio или `./gradlew assembleRelease` (JDK 17).

Код — Kotlin, без сторонних библиотек, только Android framework:

```
app/src/main/java/com/lawyye/wired/
  HomeActivity.kt      рабочий стол, жесты, часы, системные показатели
  DrawerView.kt        терминальный список приложений с поиском
  SettingsActivity.kt  NAVI://CONFIG
  CrtOverlayView.kt    полосы, виньетка, глитч-блоки
  GlitchTextView.kt    часы с RGB-сдвигом
  DataStreamView.kt    фоновый «код»
  HudFrameView.kt      перекрестия и точки
  WinDialog.kt         меню в виде старых окон
```

Ключ подписи `app/wired.keystore` лежит в репозитории специально — чтобы каждая сборка CI обновляла предыдущую. Для личного использования этого достаточно.
